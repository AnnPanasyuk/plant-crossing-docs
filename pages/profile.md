# Page: Profile

Особиста сторінка користувача. Доступна тільки авторизованим.
URL: `/profile/[tab]` для deep linking.

---

## Layout

```
[ Header ]
[ Profile Header: аватар + ім'я + місто + кнопка редагувати ] ← скролиться
[ Таби sticky ]
[ Контент активного табу ]
[ Footer ]
```

---

## Profile Header

Верхня секція яка скролиться разом зі сторінкою.

**Анатомія:**
```
[ Avatar lg ]  [ Ім'я Прізвище   ]  [ Button ghost "Редагувати" ]
               [ Місто           ]
               [ Дата реєстрації ]
```

**Правила:**
- Avatar: 80px, `var(--radius-full)`
- Телефон не показується
- Кнопка "Редагувати" праворуч → відкриває `EditProfileModal`

---

## Таби

Горизонтальні таби — sticky під глобальним хедером.
Контент рендериться і запити виконуються тільки при активації табу (lazy).

| Таб | URL | Контент |
|-----|-----|---------|
| Мої оголошення | `/profile/listings` | Список власних PlantCard |
| Замовлення | `/profile/orders` | Список покупок |
| Обміни | `/profile/swaps` | Список обмінів |
| Вішліст | `/profile/wishlist` | Збережені PlantCard |

**Правила:**
- Sticky: `top` = висота глобального хедера
- Z-index: 45 (між хедером і основним контентом)
- Активний таб — підкреслення `border-bottom: 2px solid var(--color-text-primary)`
- Default таб при відкритті: "Мої оголошення"
- URL оновлюється при зміні табу — підтримка deep linking і back/forward навігації
- На `sm`: таби скролляться горизонтально якщо не вміщуються
- Background табів при sticky: `var(--color-base-canvas)` з `backdrop-filter: blur(12px)`

---

## Таб: Мої оголошення

**Запит:** `GET /api/listings?userId={id}`

**Анатомія:**
- `Button primary` "Додати оголошення" — над гріддом
- Грід `PlantCard` власних оголошень
- На кожній картці додаткові екшени: Редагувати · Деактивувати

**Стани:**
- Завантаження → Skeleton грід
- Є оголошення → грід
- Немає оголошень → `EmptyState` + CTA "Додати перше оголошення"

## EditProfileModal

Модальне вікно редагування профілю.
Відкривається по кліку кнопки "Редагувати" в Profile Header.

**Анатомія:**
1. Заголовок: "Редагувати профіль" + кнопка × закрити
2. `ImageUpload` — фото профілю (поточне фото як preview)
3. `Input` Ім'я (`autocomplete="name"`)
4. `Input` Місто (з autocomplete)
5. `Input` Email (`autocomplete="email"`)
6. Footer модалу:
    - `Button ghost` "Скасувати"
    - `Button primary` "Зберегти"

**Правила:**
- Border radius: `var(--radius-xl)`
- Shadow: `var(--shadow-drawer)`
- Закривається: кнопка × · кнопка Скасувати · клік на backdrop · Escape
- Після збереження: модал закривається + Toast success "Профіль оновлено"
- Валідація inline — помилки під полями без сабміту
- Зміна пароля і видалення акаунту — окремі флоу, не в цьому модалі (post-MVP або окрема сторінка налаштувань)

## Що не робимо (MVP)

- Таб "Налаштування" — замінено кнопкою "Редагувати" в Profile Header

- Історія активності — post-MVP
- Рейтинг і відгуки — post-MVP
- Multiple wishlists — post-MVP
- Завантажувати контент всіх табів одразу
