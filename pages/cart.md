# CartDrawer — поведінка

Кошик реалізований як `CartDrawer` — без окремої сторінки `/cart`.
Додавати товари можна без авторизації. Логін запитується тільки при checkout.

---

## Відкриття / закриття

**Відкривається:**
- Клік на іконку кошика в хедері
- Автоматично після кліку "Придбати" на сторінці деталей або в каталозі

**Закривається:**
- Клік на кнопку ×
- Клік на backdrop
- Клавіша Escape (desktop)
- Кнопка "Продовжити шопінг"

---

## Візуальні правила

- Desktop: side drawer справа, `width: 25vw`, `min-width: 300px`
- Mobile: bottom sheet (окремий дизайн)
- `border-radius: var(--radius-xl)` на лівих кутах (drawer) / верхніх (bottom sheet)
- `box-shadow: var(--shadow-drawer)`
- Backdrop: `z-index: 65`, `backdrop-filter: blur(5px)`, перекриває хедер
- Drawer: `z-index: 70`

## Стани

### Empty state — кошик порожній

**Ширина:** ~25–30vw

**Анатомія:**
```
[ Ілюстрація (горщик) ]
[ Текст-копірайт ]
[ Посилання "До каталогу" → ]
────────────────────────────
[ Може сподобатись ]
[ PlantCard ] [ PlantCard ] [ PlantCard ]
```

**Правила:**
- 3 PlantCard у сітці 3 колонки — компактний portrait варіант
- PlantCard з wishlist кнопкою, назвою, ціною, містом
- Посилання "До каталогу" — закриває drawer і переходить на `/`

---

### Filled state — є товари

**Ширина:** ~40vw

**Анатомія:**
```
[ Може сподобатись (1/3) ] | [ Кошик · N рослин      × ]
                           | ─────────────────────────────
[ PlantCard               ] | [ CartItem               ]
[ PlantCard               ] | [ CartItem               ]
[ PlantCard               ] | [ CartItem               ]
[ PlantCard               ] | ─────────────────────────────
[ PlantCard               ] | [ Разом         1 570 ₴ ]
[ PlantCard               ] | [ Button primary "Оформити"  ]
[ PlantCard               ] | [ Button ghost  "Продовжити шопінг" ]
[ PlantCard               ] |
[ PlantCard               ] |
```

**Ліва колонка (1/3) — рекомендації:**
- 8 PlantCard, вертикальний скрол
- Фон — page gradient (`#EEF0EC → #E4E8E6`)
- Compact варіант PlantCard (portrait, з wishlist кнопкою)
- Бордер справа відділяє від кошика

**Права колонка (2/3) — кошик:**
- Список `CartItem` зі скролом
- Підсумок + кнопки внизу, `flex-shrink: 0`

---

## CartItem

**Анатомія:**
```
[ Фото 72×72 ]  [ Назва рослини     ] [ × видалити ]
               [ Продавець · Місто  ]
               [ Ціна    ] [ Stepper − N + ]
```

**Правила:**
- Фото: `72×72px`, `border-radius: var(--radius-md)`, `aspect-ratio: 1/1`
- Назва: `font-size: 13px`, `font-weight: 500`, `text-overflow: ellipsis`
- Ціна і stepper — в одному рядку, вирівняні по низу (`align-items: center`)
- Кнопка × — справа зверху, `color: rgba(0,0,0,0.18)`, hover → `rgba(191,61,82,0.55)`
- `overflow-x: hidden` — горизонтальний скрол виключений

**Stepper:**
- Компонент `AddToCartButton` — primary variant (рожевий градієнт)
- Кнопки `−` і `+` по 22×22px, `border-radius: 50%`
- Якщо залишився 1 екземпляр — `+` задізейблений
- Tooltip на hover задізейбленого `+`: `"Залишився 1 екземпляр"`
- Tooltip центрується відносно кнопки `+`

**Рослини "тільки обмін" в кошик не потрапляють.**

---

## Підсумок

- Показується тільки загальна сума в ₴
- Позиції "тільки обмін" в суму не входять (і в кошик не потрапляють)
- Без розбивки по позиціях (вона на сторінці `/checkout`)

---

## Checkout flow

**Тригер:** клік "Оформити"

| Стан | Поведінка |
|------|-----------|
| Без логіну | Drawer закривається → відкривається `AccountPopup` |
| Після авторизації | Повернення до checkout → перехід на `/checkout` |
| З логіном | Перехід на `/checkout` |

`/checkout` — єдина окрема сторінка cart flow.

---

## Stock конфлікт

Виявляється тільки при спробі оформити:
- Toast з поясненням
- Проблемний `CartItem` підсвічується (деталі — окремий дизайн)
- Stock кількість в drawer не показується — тільки при конфлікті

## Авторизація

| Дія | Без логіну | З логіном |
|------|-----------|-----------|
| Відкрити кошик | ✅ | ✅ |
| Додати товар | ✅ | ✅ |
| Видалити товар | ✅ | ✅ |
| Оформити | → AccountPopup | → `/checkout` |

---

## Стан між сесіями

- Zustand з `persist` (localStorage)
- Кошик зберігається між сесіями без авторизації
- Додається в Phase 2

---

## Що не робимо

- Окрема сторінка `/cart`
- Показувати stock кількість в drawer — тільки при конфлікті
- Hover ефекти на `sm` і `md`
- Горизонтальний скрол де-небудь
- Слайдери, dropdowns
