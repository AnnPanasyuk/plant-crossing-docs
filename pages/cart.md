# Page: Cart

Кошик реалізований як `CartDrawer` — без окремої сторінки кошика.
Додавати товари можна без авторизації. Логін запитується тільки при checkout.

---

## Layout

```
[ Основна сторінка (каталог або деталі) ]
[ CartDrawer — overlay справа (lg) або знизу (sm/md) ]
```

---

## Тригери відкриття

- Клік на іконку кошика в хедері
- Додавання товару в кошик (drawer відкривається автоматично)

---

## CartDrawer

**Компонент:** `CartDrawer`

### На `lg` (десктоп) — Side Drawer
```
[ × ]
[ Кошик (N) ]
─────────────────
[ CartItem ]
[ CartItem ]
─────────────────
[ Підсумок ]
[ Разом: 1 200 ₴ ]
[ Button primary lg "Оформити" ]
[ Button ghost "Продовжити шопінг" ]
```

### На `sm`/`md` (touch) — Bottom Sheet
```
────── [ drag handle ] ──────
[ Кошик (N) ]           [ × ]
─────────────────────────────
[ CartItem ]
[ CartItem ]
─────────────────────────────
[ Разом: 1 200 ₴ ]
[ Button primary lg "Оформити" ]
[ Button ghost "Продовжити шопінг" ]
```

**Візуальні правила:**
- Border radius: `var(--radius-xl)` (ліві кути для drawer, верхні для bottom sheet)
- Shadow: `var(--shadow-drawer)`
- Background: `var(--color-base-canvas)`
- Z-index: 40 (див. `layout/grid.md`)
- Backdrop: напівпрозорий оверлей поза drawer

**Поведінка:**
- Закривається: клік на backdrop · кнопка × · Escape (lg) · свайп вниз (sm/md)
- "Продовжити шопінг" → закриває drawer, повертає фокус на сторінку

## CartItem

**Компонент:** `CartItem`

**Анатомія:**
```
[ Фото ]  [ Назва рослини        ] [ × ]
          [ Ім'я продавця        ]
          [ Ціна                 ]
```

**Правила:**
- Фото: маленьке, border radius `var(--radius-md)`, aspect ratio 1:1
- Кнопка × — видалення з кошика
- Кількість не показується (один екземпляр рослини = одна позиція)
- Конфлікт stock — показується тільки при спробі checkout (Toast)

---

## Checkout флоу

**Тригер:** клік "Оформити" в `CartDrawer`

### Без логіну:
1. Клік "Оформити"
2. `CartDrawer` закривається
3. `AccountPopup` відкривається з login/signup формою
4. Після авторизації → повернення до checkout

### З логіном:
1. Клік "Оформити"
2. Перехід на сторінку `/checkout` (окрема сторінка)

**Правила:**
- `/checkout` — єдина окрема сторінка cart флоу
- Stock кількість зберігається в БД
- При конфлікті stock під час checkout → Toast з поясненням

## Empty State

Якщо кошик порожній:

```
[ EmptyState ілюстрація ]
"Кошик порожній"
"Знайди свою рослину в каталозі"
[ Button primary "До каталогу" ]
```

---

## Стани

| Стан | Поведінка |
|------|-----------|
| Порожній | EmptyState з CTA |
| З товарами (гість) | CartItem список, checkout → логін |
| З товарами (авторизований) | CartItem список, checkout → `/checkout` |
| Конфлікт stock | Toast при checkout, проблемний CartItem підсвічується |

## Що не робимо

- Окрема сторінка `/cart` — все в drawer
- Показувати stock кількість в drawer — тільки при конфлікті
- Hover ефекти на `sm` і `md`
- Слайдери, dropdown, calendar picker
