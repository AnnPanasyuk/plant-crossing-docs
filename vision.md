# PlantCrossing: Vision & Strategy

## Primary Goal
Building a platform for exchanging indoor plants in Ukraine. Preparing to return to Scalr in summer 2026 by demonstrating technical expertise.

## Technology Strategy
We use Scalr's technology stack as a reference point, but the primary priority is fitness for purpose in our specific context. Our goal is to show that we can make better decisions than those currently in place at Scalr.

## Tech Stack (Reference)
* **Frontend:** React, Next.js (App Router)
* **Backend:** Node.js (custom implementation)
* **Data:** PostgreSQL (Prisma/Drizzle), Headless CMS for the catalog
* **AI:** Integration of solutions for code automation and user assistance

## Core Roles & Features
* **Collector:** Adding plants, managing a home jungle
* **Seeker:** Searching for exotic plants, filtering by care difficulty
* **Swopping System:** Proposal mechanics and chat functionality
* **AI Assistant:** User history analysis, plant care suggestions

## Design & UX
Based on an existing prototype with interactive maps for major Ukrainian cities.
