# Header Layout

Глобальний хедер присутній на всіх сторінках платформи.

---

## Структура

Трьохколонковий layout:
[ Лого ]        [ Пошук ]        [ + Акаунт Кошик ]

### Колонка 1 — Лого
- Ліворуч
- Клік → головна сторінка (каталог)

### Колонка 2 — Пошук
- По центру
- Завжди видимий інпут на десктопі та планшеті
- На мобайлі: іконка пошуку → розгортає інпут на повну ширину

### Колонка 3 — Іконки (праворуч, зліва направо)
1. **Нове оголошення** (`+` іконка)
    - Десктоп: іконка з підписом або ghost кнопка
    - Мобайл: FAB (floating action button) внизу праворуч — з хедера прибирається
    - Клік без логіну → тригерить login попап
2. **Акаунт** (іконка юзера)
    - Клік → попап (3 сценарії, див. нижче)
3. **Кошик** (іконка кошика)
    - Badge з кількістю товарів
    - Клік → відкриває side drawer
    - Додавати товари можна без логіну

---

## Сценарії акаунт-попапу

### Сценарій 1 — Гість (не авторизований), signup
Показує форму реєстрації inline у попапі.
Поля: ім'я, фото (обов'язкове), місто (обов'язкове), email.
Під кнопкою: `Реєструючись, ти погоджуєшся з [Умовами використання]`
SSO: Google, Apple — основні. Email/password — опціональний.

### Сценарій 2 — Гість, login
Показує форму входу inline у попапі.
Посилання "Забули пароль?" під полем пароля.
SSO: Google, Apple.

### Сценарій 3 — Авторизований користувач
Показує:
- Ім'я + прізвище
- Email
- 4 посилання: Профіль · Замовлення · Обміни · Вішліст
- Кнопка виходу

## Поведінка при скролі

Хедер — sticky (залишається вгорі при скролі).
При скролі вниз: frosted glass ефект підсилюється.
```css
backdrop-filter: blur(12px);
background: rgba(253, 248, 246, 0.85);
```

---

## Адаптивність

| Breakpoint | Поведінка |
|------------|-----------|
| Desktop (≥1024px) | Всі три колонки, пошук розгорнутий |
| Tablet (768–1023px) | Всі три колонки, пошук трохи вужчий |
| Mobile (<768px) | Лого + іконка пошуку + іконка акаунту + іконка кошика. FAB для нового оголошення |

---

## Що не робимо

- Hover-reveal для пошуку — не працює на тач
- Hover-reveal для нового оголошення — не працює на тач
- Темний фон хедера — конкурує з контентом
- Яскравий announcement bar — порушує тональність
